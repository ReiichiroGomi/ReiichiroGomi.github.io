# サイト編集ガイド

このサイトのオーナー（[@ReiichiroGomi](https://github.com/ReiichiroGomi)）が運営するポートフォリオサイトのリポジトリです。

- 公開URL: https://reiichirogomi.github.io/
- 1ファイル完結: `index.html` に HTML / CSS / JS が全部入り（約2000行）
- 編集の目印として、HTML 内に日本語コメント（`▼ ここを編集`、`【◯◯】` 見出し など）が大量に埋め込まれている

## サイトを更新する3つの方法

### 方法1: Claude Cowork で頼む（デスクトップアプリ・GUI）
1. Claude デスクトップアプリを開いて **Cowork タブ**
2. このリポジトリのフォルダを Cowork に追加（初回のみ）
3. 「〇〇を直して」と日本語で依頼するだけでファイル編集まで完了

**注意:** Cowork タブは「ファイル編集」が中心で、git の commit / push までは標準では行いません。本番サイトに反映するには次のどちらかが必要：

- **同じデスクトップアプリの「Code」タブ**に切り替えて「コミットして push して」と頼む（同じアプリで完結する楽な方法）
- または、後述の **方法3「VSCode で自分で編集」の手順 4** にある「ソース管理 → コミット → 同期（プッシュ）」を実行

### 方法2: Claude Code で頼む（コマンドライン）
1. **初回だけ** インストール:
   ```
   npm install -g @anthropic-ai/claude-code
   ```
2. ターミナルでリポジトリのフォルダに移動して `claude` と入力
3. あとは Cowork と同じく日本語で依頼

### 方法3: VSCode で自分で編集（GitHubに慣れたら）
1. **初回だけ**: ローカルにコピー
   - VSCode → 左サイドの「ソース管理」アイコン → 「リポジトリのクローン」
   - URL欄に: `https://github.com/ReiichiroGomi/ReiichiroGomi.github.io.git`
   - 保存先フォルダを選んで OK
2. **編集する前に毎回**: 最新の状態に更新（誰かが変更してるかもしれないため）
   - VSCode → ソース管理 → 「・・・」メニュー → 「プル」
3. `index.html` を編集して保存
4. ソース管理 → コミットメッセージを書く → 「コミット」→ 「同期（プッシュ）」
   ※ `main` ブランチに push すると即本番公開（数十秒〜数分で反映）

## Issue（やりとり・記録用）

「サイトをこう変えたい」「これってどうなってる？」など、**要望や質問は Issue に書く** 運用にしています。Webブラウザでこのリポジトリのページを開いて、「**Issues**」タブから見られます。

### Issue にコメントを書く
1. リポジトリの「Issues」タブを開く
2. 既存の Issue（例: Issue #1）があれば、画面下の「Add a comment」に書く
3. 新しい話題なら右上の「New Issue」で立てる
4. **必ず `@相手のGitHubアカウント名` でメンションを付ける**（しないと相手に通知が届かない）

### チェックリスト記号の意味
Issue 本文にチェックリストがある場合、こんな意味で使います：
- `[x]` 対応完了
- `[ ]` 未対応（今後やるかも）
- `[ ] ~~取り消し線~~ — 理由` 検討の上やらないと決定

## 編集時のお願い

- `index.html` の中の **日本語コメント** （`▼ ここを編集`、`【◯◯】` 見出し、料金表の編集要領 など）は **削らない**。編集の目印になっている
- `main` ブランチへの push は即本番公開なので、コミット前に必ずブラウザでプレビュー確認
- 画像は `images/` フォルダの中だけに置く（それ以外には置かない）

## おまけ: Pull Request（PR）という仕組みもある

複数人で開発するときによく使う仕組みで、「`main` に直接 push する代わりに、別ブランチで変更を作って『これマージしていい？』とレビューを通してから反映する」やり方です。
今は `main` 直push でシンプルに運用していますが、将来「失敗したくない大きめ修正」とか「レビューしてから反映したい」場合は PR の運用に切り替えられます。必要になったタイミングで相談してください。
